# UDGAM 2K26 – Landing Page

Single-file website for UDGAM 2K26, NIT Sikkim. Open `index.html` in a browser – no build step.

## Pages
Home · About · Events · Legacy · Memories · Gallery · Sponsors · Team · Contact
(use the blossom button at the top-left or the Ferris wheel on the right edge to navigate)

## Editing
- **Team** – search for `Team page` in `index.html`. Each lead has a name, role, committee and a Google Drive photo id (`p`) or an image link (`i`).
  Drive photos only show if the file is shared as "Anyone with the link can view".
- **Sponsors** – replace each `.sp-slot` block with `<img src="logo.png" alt="Sponsor name">`.
- **Gallery** – set each tile's `data-img` to a photo link.
